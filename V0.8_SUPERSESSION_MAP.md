# v0.8 → v0.9 Supersession Map

This package is the active consolidated specification. v0.8 remains a historical prior version. Do not mix old audit prompts or implementation instructions with v0.9.

| v0.8 area | v0.9 treatment |
|---|---|
| Open-world discovery | Preserved as first-class catalyst-led and anomaly-led discovery outside watchlists. |
| Market Episode learning core | Preserved as the context/event response research unit. |
| Gameplay/pattern lifecycle | Clarified; distinguishes Setup Family, Setup Definition Version, Setup Instance, Entry Scenario and Parameter Experiment. |
| Stock Character / fundamentals / UBO | Linked as point-in-time feature context for each setup occurrence, not flattened into one score. |
| Personal Edge | Evaluates the user's observed/selected/executed subset against the broader market-wide setup population. |
| Entry parameters | Separate hypothetical scenarios, including distance from MA10 and MA20; never actual fills. |
| Learning methodology | Adds reproducible scan denominators, non-matches, occurrence grouping, cross-issuer dependence and robust parameter-region analysis. |
| Roadmap | Adds a dedicated setup-instance/parameter-learning sprint before Personal Edge. |
| Agent prompts | Replaced by v0.9 read-only audit prompts. |

Use `README.md`, `AGENTS.md`, `CLAUDE.md`, `CODEX_START_HERE_v0.9.md` and the v0.9 docs as the only active requirements.
